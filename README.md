# 📚 智能文档问答系统

基于文档内容的精准AI问答与测验平台，提供流畅的文档问答体验和知识巩固功能。

## ✨ 核心功能

### 💬 智能对话问答
- **多格式文档上传**：支持 PDF、DOCX、TXT、PPTX、图片等多种格式
- **精准文档问答**：基于上传文档内容进行精准AI回答
- **可配置检索**：可自定义设置检索片段数量（1-10段）
- **上下文理解**：支持多轮对话，理解上下文语境
- **引用追踪**：显示回答引用的具体文档片段和来源

### 📝 智能测验生成
- **题目自动生成**：基于对话历史自动生成测验题目
- **多种题型**：支持选择题、填空题、简答题
- **智能判分**：自动批改答案并给出详细解析
- **学习分析**：提供综合学习表现分析和改进建议
- **错题回顾**：详细展示答题情况和标准答案

## 🚀 快速开始

### 1. 上传文档
点击左侧上传区域或直接拖拽文件到上传区域，支持同时上传多个文件（最多5个）。

### 2. 提问互动
在输入框中输入关于文档内容的问题，点击发送或使用 `Ctrl/Cmd + Enter` 快捷键提交。

### 3. 生成测验
勾选助手回答消息，设置出题数量，点击「生成测验」按钮跳转到测验页面。

### 4. 完成测验
在测验页面回答问题，提交后查看判分结果和详细解析。

## 🛠️ 技术特性

### 前端优化亮点
- 🎨 **现代化UI设计**：参考印象笔记风格的简洁优雅界面
- 📱 **响应式布局**：完美适配桌面端和移动端
- ⚡ **流畅交互体验**：丰富的动画效果和交互反馈
- 🎯 **直观的视觉层次**：清晰的信息架构和视觉引导
- 🔧 **便捷快捷键**：支持多种操作快捷键

### 支持的文件格式
- **文档类**：PDF, DOCX, DOC, TXT, MD, HTML
- **表格类**：XLSX, XLS
- **演示类**：PPTX, PPT
- **图片类**：PNG, JPG, JPEG, WebP, BMP, GIF, TIFF

### 快捷键支持
- `Ctrl/Cmd + Enter`：发送问题 / 提交测验
- `Ctrl/Cmd + L`：清空聊天记录
- `Shift + Ctrl/Cmd + R`：重置测验答题

## 🎨 设计理念

### 视觉风格
采用印象笔记式的简洁优雅风格：
- **主色调**：柔和的绿色系，传达知识、成长和活力
- **中性色**：多层次的灰度，营造专业、沉稳的氛围
- **卡片设计**：清晰的信息层级和视觉分割
- **微交互**：精致的悬停效果和过渡动画

### 用户体验
- **直观操作**：符合用户直觉的交互设计
- **即时反馈**：丰富的操作反馈和状态提示
- **错误处理**：友好的错误提示和恢复机制
- **无障碍设计**：支持键盘导航和屏幕阅读器

## 🔄 数据同步

- **会话持久化**：聊天记录和文件上传状态自动保存
- **跨页同步**：对话和测验数据无缝同步
- **进度保存**：答题进度自动保存，支持中途退出后恢复

- **懒加载**：按需加载资源，提升首屏速度
